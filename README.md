# Particle demo engine (NASM, Win32)

A small 32-bit Windows demo engine written in NASM, built around an **SSE stack-machine VM** that evaluates
formulas to place particles. Every scene is a set of GL points (`GL_POINTS`): a landscape layer plus an object layer,
driven by the audio position of the music. No Python anywhere: the build and the dev tools are plain C and shell,
and the only tools needed are `nasm` and `ld` (MinGW / binutils).

Coder: **Ivandoe**

> Status: the engine was built and checked with a Linux test bench (same frame logic, software renderer, a Mesa
> llvmpipe run of the shader). The Windows executable has **not been run on a real Windows machine yet**, and the
> synchronisation with the music has been verified by signal analysis, not by ear.

## Features

- **Formula VM** (`src/core/vm.inc`): 4 points per SSE operation, noise / fBm / ridged noise, atan2, log2/exp2,
  hashing, rotations, Euler integration. Programs are written as macros or generated from infix expressions
  (`tools_src/ex2vm.c`).
- **Two-layer scenes** (`src/core/engine.inc`): layer 0 = infinite polar-grid landscape (300 000 points, reliefs,
  water reflections, sky dome, volcanoes with lava projections), layer 1 = the main object (strange attractors,
  minimal surfaces, fractals, hypertorus, galaxy...).
- **Music sync** (`src/core/mus.inc`, `tools_aud/`): the audio playback position drives every frame. The song is
  analysed offline into 50 Hz tables (4 band levels, attack age, pitch, instrument, row position, beat/bar grid);
  scene starts are aligned on bars.
- **Group morphing** (`src/core/morph.inc`): transitions between scenes pair points by Morton-order rank, group by
  group (landscape to landscape, object to object), with 8 transition styles (swirl, rising wave, circular wave,
  explosion, implosion, geyser, counter-swirl, spiral + wave), per-point easing, and camera blending.
- **Per-scene camera profiles** (`src/camtab.inc`, generated by `src/gen/gencam.sh`): each scene has its own
  elevation, heading, distance, jump size/direction mode, dolly punch, glide rate and slow push. The camera always
  looks at the object and only moves on the kick drum.
- **Post-processing** (`src/postfx.inc`, `src/gen/postfx.frag`): GLSL 1.10 fullscreen shader with per-scene
  effects (ripple, swirl, lens, breathing zoom, radial blur, streak blur, halftone, RGB split, posterize,
  emboss...), different for the background and the objects. Automatically disabled if shaders are unavailable.
- **Settings window** (`src/setup.inc`): resolution, 30/60 fps, quality, music on/off, effects on/off,
  windowed/fullscreen, and an **Export MP4** button. See also the standalone version of this window.
- **Frame-by-frame MP4 export**: offline render at `time = frame / fps`, music written as WAV, frames piped to
  `ffmpeg` (needs `ffmpeg.exe` next to the exe or in `PATH`).
- **Live sync trim**: left / right arrow keys shift the picture against the audio by 1 ms per frame held.
- **Quality levels**: low / medium / high change the point stride and compensate the point size.

## Repository layout

```
src/intro.asm          entry point, window + GL context, audio ring (waveOut), main loop, export
src/setup.inc          settings window (dialog built in memory)
src/postfx.inc         shader post-processing
src/core/              engine: vm, engine (scenes/layers), frame (per-frame logic + camera), morph,
                       fx_common (constants, math helpers), mus (ADPCM mixer + tables), palettes, scenes
src/lib/               VM macros (vmmac.inc, modshape.inc)
src/scenes/            landscapes (land*.inc), objects (obj*.inc), text (title.inc), scene list (list.inc)
src/gen/               generators (shell/awk + .ex formula files): objects, reliefs, volcanoes, scene list,
                       camera profiles, shader/effect tables
src/res/               exe icon and logo resources (prebuilt COFF object icon.o)
music/                 analysis tables and ADPCM header (the audio file itself is NOT included)
libs/imp32/            import libraries for kernel32, user32, gdi32, opengl32, winmm
test/                  Linux test bench (`sim`) running the real frame logic
tools_src/             C tools: ex2vm, render (software preview), camtraj, icon / resource builders
tools_aud/             C tools: audio analysis, ADPCM codec, scene scheduling
build.sh / build.bat   build scripts (Linux / Windows)
```

## Build

Requirements: `nasm`, `ld` (MinGW or binutils with the `i386pe` emulation). `upx` is optional.

```sh
sh build.sh        # Linux      -> bin/demo.exe
build.bat          # Windows (MinGW in PATH)
```

### The music is not included

`music/track.adp` (the demo's song) is **not** part of this repository. To build you need your own track:

```sh
cd tools_aud
gcc -O2 -o audana   audana.c   -lm
gcc -O2 -o adpcm    adpcm.c    -lm
gcc -O2 -o schedule2 schedule2.c -lm
ffmpeg -i song.mp3 -ac 2 -ar 44100 -f s16le song.s16
./audana song.s16 ../music            # t_lvl/t_age/t_pit/t_ins/t_pos.bin, track.inc, bars.txt
./adpcm enc song.s16 ../music/track.adp ../music/adp_tab.inc
./schedule2 ../music/bars.txt NFRAMES NSCENES > ../src/gen/starts30.txt
```

Then regenerate the scene list (`src/gen/genlist.sh starts30.txt scenes30.txt > src/scenes/list.inc`) and rebuild.
The `t_*.bin` tables and `starts30.txt` currently in the repository belong to the original song and must be replaced
with the ones produced for yours. See `tools_aud/README.txt`.

## Writing scenes

- **Landscapes**: `TERRAIN` macro in `src/scenes/land.inc`; a relief is a stack program returning a height from
  `(x, z)`. Extra reliefs can be written as infix expressions in `src/gen/reliefs.ex` and compiled by
  `src/gen/genrel.sh`.
- **Objects**: write the formulas in `src/gen/objs5.ex` (infix, variables `t0..t15`, `u`, `v`, music levels
  `l0..l3`...) and run `src/gen/gen.sh`, or write VM macros by hand (see `src/scenes/obj*.inc`).
- **Scene list**: `src/gen/scenes30.txt` (relief, background palette, object, object palette, point size) plus
  `starts30.txt` (bar-aligned start frames) are turned into `src/scenes/list.inc` by `genlist.sh`.
- **Camera / effects**: `gencam.sh` (`src/camtab.inc`) and `genfx.sh` (`src/fxtab.inc`, `src/postfx_src.inc`).

## Development tools

```sh
gcc -O2 -o camtraj tools_src/camtraj.c && gcc -O2 -o render tools_src/render.c -lm
sh test/build.sh                                   # builds the Linux test bench ./test/sim
./test/sim 0 15160 1 | ./camtraj                   # camera trajectory check (frame scene rx ry d roll ...)
./test/sim 1000 1100 50 > dump.bin && ./render dump.bin out 960 540 6.0   # software preview PNGs
```

`render` (from `tools_src/render.c`) reproduces the point rendering rules of `intro.asm` in software, so scenes can
be inspected without OpenGL. The shader itself was only checked with Mesa llvmpipe.

Icon / resource tools: `mkicon.c`, `mkexp.c` (SVG export icon) and `mkrsrc.c` (rebuilds `src/res/icon.o`). The import
libraries were generated with `llvm-dlltool -m i386 -k -d X.def -l X.lib` (definitions in `tools_src/*.def`).
